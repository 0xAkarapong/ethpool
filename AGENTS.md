# AGENTS.md

## Commands

```bash
bun install            # Bun only — no npm/pnpm in this repo (bun.lock)
bun --bun run dev      # dev server on http://localhost:3000 (note --bun)
bun test               # runs *.test.ts with bun:test (no vitest/jest)
bun test src/lib/format.test.ts -t "fee bands"   # single file / single test
bun run build          # vite build (TanStack Start + nitro)
bunx tsc --noEmit      # typecheck — no package.json script exists for it
bun run lint           # eslint
bun run format         # prettier --write . then eslint --fix
bun run generate-routes  # tsr generate — regenerates src/routeTree.gen.ts
bun run storybook      # port 6006
```

Q&A: `bun run check` is prettier-only; use `bunx tsc --noEmit` before declaring work done.

## Gotchas

- `src/routeTree.gen.ts` is generated by TanStack Router. Never edit it; after adding/removing files in `src/routes/`, run `bun run generate-routes` (the dev server does this automatically, but it is not run for you in tests/CI).
- `tsconfig.json` excludes `**/*.test.ts`; eslint also ignores them. Tests are plain `bun:test`, colocated next to the file they cover, and hit no network.
- Two import aliases map to the same `src/`: `#/*` (Node subpath import, defined in `package.json` `imports`) and `@/*` (tsconfig paths). Both work; files mix them.
- Tailwind 4 is CSS-first: config lives in `src/styles.css`, there is no `tailwind.config.*`.
- No API keys or env vars are ever required. All data comes from public Ethereum RPC endpoints via the failover client in `src/lib/rpc.ts` (race across 6 hosts, 4s per-attempt timeout, 20s quiet period for bad hosts).
- shadcn/ui components live in `@/components/ui` (see `components.json`); icon library is Phosphor (`@phosphor-icons/react`), not lucide.

## Structure

TanStack Start (SSR fullstack React 19) on Vite + nitro; deployed on Vercel (`vercel.json` pins `tanstack-start`).

- `src/routes/` — file-based routes. Server work happens in route `loader`s (e.g. `getBlockView(...)`); components below read `Route.useLoaderData()`.
- `src/lib/chain/` — Ethereum data layer: blocks (`block.ts`), transactions (`tx.ts`), addresses/ENS (`address.ts`), hex/wei decoding (`hex.ts`, `parse.ts`, `tokens.ts`), all via `src/lib/rpc.ts`.
- `src/components/` — UI; shared shell/hooks (`useAutoRefresh`, `useStickyOk`, `useReportHost`) in `shell.tsx`/`shell-state.ts`. Pages auto-refresh live data every 20 s.
- All values are BigInt wei internally; format for display only in `src/lib/format.ts`.

## Testing note

Tests verify pure logic (formatters, merge/treemap, chain parsing) against fixtures — when changing numeric units, time formatting, `src/lib/chain/*`, or `src/lib/treemap.ts`, check the matching `*.test.ts` for hard thresholds that encode design intent (e.g. fee bands 17/22 gwei, chart `axisMax`).
